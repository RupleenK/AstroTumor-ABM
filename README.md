# AstroTumor-ABM  
Agent-Based Model for Astrocyte–Tumor Interactions

**AstroTumor-ABM** is a Java-based simulation (built on HAL) that models how tumor-associated astrocytes switch states and generates spatial morphology metrics (lacunarity, eccentricity, fractal dimension). Python analysis modules process the CSV outputs to reproduce all figures in our publication.
